## 先分清是哪一种「锁定」

「锁定」是用户自己的说法，系统给的提示其实分成四种，处理方式完全不同。**判断错了就会白折腾一整天。**

| 你看到的提示 | 真实含义 | 能否自救 |
|---|---|---|
| Apple ID 已被锁定 / locked for security reasons | 密码输错太多次，或异地登录触发风控 | ✅ 能，重设密码即可 |
| 此 Apple ID 已在 App Store 和 iTunes 中被禁用 | 被判定违反条款（异常下载、批量登录） | ⚠️ 部分能，要联系 Apple 支持 |
| 需要验证 / 需要受信任设备 | 触发了双重认证 | ❌ 共享号基本无解 |
| 无法登录，用户名或密码错误 | 密码被管理员改了（不是锁定） | ✅ 换号即可 |

**第三行是最容易误判的。** 很多人看到「需要验证」以为是网络问题，反复重试，其实这个账号已经不在你能控制的范围里了——原因见下一节。

## 共享号为什么会被锁（三个真实原因）

共享号本身是「多人轮流登录同一个 Apple ID」，这种用法天然踩在风控线上。实际导致锁定的，九成是这三件事：

**① 登录了 iCloud**

这是第一杀手。App Store 和 iCloud 是两个入口，但用的是同一个 Apple ID。只登 App Store 下载应用没问题；一旦登了 iCloud，设备就和这个账号绑定了——原持有人一改密码，你的设备会被远程锁定，界面上提示的往往就是「需要验证」或直接变砖。

**② 开了双重认证**

共享号一旦被某个使用者开了双重认证，受信任设备就绑在他的手机上。之后所有人登录都会卡在「输入验证码」，而验证码只有他有。这个号等于废了。

**③ 多人同时在线触发风控**

同一个账号短时间内从多个 IP、多个地区登录，Apple 会直接判定为异常并锁定。这是共享号的固有缺陷，跟你操作是否正确无关。

还有第四个原因，但性质不同：**尝试内购或充值**。共享号的支付方式不属于你，任何内购都会被拒，并且大概率触发封禁。

## 自己买的独享号被锁了，怎么救

独享号（能自己改密码、绑邮箱的那种）被锁，大部分是能救回来的，按顺序走：

**第一步：确认控制权还在你手里**

去 `iforgot.apple.com`，输入账号。如果系统让你「回答安全问题」或「发送验证码到备用邮箱」，说明控制权在你这，继续往下走。

如果提示「需要受信任设备」而你没有——说明有人在这个号上开了双重认证，控制权已经不在你手里，直接跳到下一节。

**第二步：重设密码**

能收到邮箱验证码的，走邮箱验证最快。重设后立刻登录 App Store 验证是否恢复。

**第三步：还不行就走账户恢复**

账户恢复是 Apple 的人工审核流程，快则几小时，慢则几天。期间不要反复尝试登录——每次失败都会重置等待时间。

## 什么时候彻底无解

这三种情况别再花时间了：

1. **原持有人通过客服申诉找回了账号**——对方能提供注册信息、历史订单，Apple 会判给他
2. **账号被判定为批量注册，整批封禁**——同一环境注册的一批号会一起死，单个救不回来
3. **密保被改且没有备用邮箱**——你既证明不了所有权，也收不到验证码

**最快的判断方法**：能不能改密保？

- 能改 → 控制权在你，有救
- 改不了、提示联系管理员 → 这是共享号，无解，换号

## 预防：三条不能破

| 规则 | 原因 |
|---|---|
| 只登 App Store，不登 iCloud | 登 iCloud = 设备被绑定 = 可能变砖 |
| 弹出「升级到双重认证」时选**稍后 / 不升级** | 开了 2FA，号就废了 |
| 不在共享号上内购、不充值 | 支付方式不是你的，必然被拒并触发封禁 |

另外一条经验：**下载完就退出登录**。留在账号里既没有好处，又增加了被风控扫到的概率。

## 常见问题

**Q：提示「已停用」和「已锁定」有区别吗？**

有。「已锁定」多为密码错误触发，能自己重设；「已停用（disabled）」通常是被判定违规，需要联系 Apple 支持，成功率低很多。

**Q：换了新号，之前下载的 App 还能用吗？**

能。应用已经装在本机，退出账号不影响使用和更新（更新时可能需要重新验证，视应用而定）。

**Q：同一个号昨天还能用，今天提示密码错误，是锁了吗？**

大概率不是锁定，是管理员按计划轮换了密码。共享号的密码本来就会定期更换，去取号页看最新密码即可。

**Q：被锁的号能找卖家换吗？**

看你买的是什么。共享号被锁通常不在售后范围（多人使用导致，责任无法界定）；独享号如果是原持有人找回，属号源问题，应当换号。这条边界最好在下单前问清楚。
